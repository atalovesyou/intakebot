# IntakeBot — AI Client Intake for Freelancers

**Replace static forms with AI-powered client qualification.** 8 industry templates, adaptive conversations, lead scoring, structured JSON output.

🔗 **Live:** [https://atalovesyou.github.io/intakebot/](https://atalovesyou.github.io/intakebot/)
🔗 **Widget Demo:** [https://atalovesyou.github.io/intakebot/widget-demo.html](https://atalovesyou.github.io/intakebot/widget-demo.html)

## The Problem

Static intake forms have 60%+ abandonment rates. Potential clients bounce before you ever talk to them. And the ones who complete forms give you unstructured data you can't act on.

## Features

- **Bot Builder** — Configure name, template, tone, welcome message, questions, qualification rules
- **8 Industry Templates** — Law, freelance, agency, coaching, real estate, healthcare, SaaS, immigration
- **Adaptive Conversations** — Deep conversation trees that adjust based on answers
- **Lead Scoring** — 0-100 score: budget + urgency + completeness → Hot/Warm/Cool
- **Intake Dashboard** — Total/completed/abandoned stats, quality distribution, history
- **Structured JSON** — Real-time data extraction as conversation progresses
- **CSV Export** — Full history export
- **Embeddable Widget** — `intakebot-widget.js`, zero deps, configurable via data attributes
- **100% Client-Side** — No data leaves browser

## Embeddable Widget

Drop this into any page:
```html
<script src="https://atalovesyou.github.io/intakebot/intakebot-widget.js"
  data-template="law" data-theme="dark" data-position="bottom-right">
</script>
```
